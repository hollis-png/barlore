You are a sports science literature researcher tasked with finding real data for a structured fitness knowledge base.

## Objective

Find EMG muscle activation data, joint ROM requirements, and strength curve characteristics for the exercises listed below.
Output one YAML block per exercise. Follow the schema strictly.

## Exercises to Research

- box_squat | known muscles: rectus_femoris, vastus_lateralis, vastus_medialis, gluteus_maximus, biceps_femoris, semitendinosus, erector_spinae, core
- front_squat | known muscles: rectus_femoris, vastus_lateralis, vastus_medialis, gluteus_maximus, core, trapezius, rhomboids
- goblet_squat | known muscles: rectus_femoris, vastus_lateralis, vastus_medialis, gluteus_maximus, core
- leg_press | known muscles: rectus_femoris, vastus_lateralis, vastus_medialis, gluteus_maximus, biceps_femoris, semitendinosus

## Search Strategy

1. Search PubMed, Google Scholar, and SPORTDiscus
2. For each exercise, use search terms: "{exercise name}" AND ("EMG" OR "electromyography" OR "muscle activation" OR "% MVC" OR "% MVIC")
3. Prefer: RCTs, n ≥ 10, trained populations, published after 2000
4. If multiple studies exist for one exercise, output ALL of them — do not merge
5. If one study tested multiple load conditions (e.g. 60% vs 80% 1RM), output each condition as a SEPARATE study block
6. If no peer-reviewed EMG data exists for an exercise, write: # {exercise_id}: no peer-reviewed EMG data found

## Output Rules — STRICTLY ENFORCED

- Output ONLY valid YAML. No prose, no markdown code fences, no preamble, no closing remarks.
- Every numeric value MUST have a corresponding source_id that appears in the sources[] list.
- If a value is not found in a source, write null. NEVER estimate or invent numbers.
- If a field does not apply to this movement, omit it entirely.
- All muscle ids must be snake_case canonical anatomical names (e.g. vastus_lateralis, not "VL" or "Quad").
- The string values "unknown", "estimated", "approximate" are forbidden.
- Each exercise block must begin with a comment line: # exercise_id: {id}
