# Push Pull Legs (PPL)

A six-day per week split grouping muscles by movement pattern: pushing muscles (chest, shoulders, triceps) train together, pulling muscles (back, biceps, rear delts) train together, and legs (quads, hamstrings, glutes, calves) train together. Each group is hit twice per week.

## Weekly Schedule

| Day | Session |
|-----|---------|
| Monday | Push A (heavy — 4-6 reps on compounds) |
| Tuesday | Pull A (heavy) |
| Wednesday | Legs A (heavy) |
| Thursday | Push B (moderate — 8-12 reps) |
| Friday | Pull B (moderate) |
| Saturday | Legs B (moderate) |
| Sunday | Rest |

## Push Day A (Heavy)

| Exercise | Sets × Reps |
|----------|-------------|
| Bench Press | 4 × 4-6 |
| Overhead Press | 3 × 8-12 |
| Incline Dumbbell Press | 3 × 8-12 |
| Cable Lateral Raise | 3 × 10-15 |
| Triceps Pushdown | 3 × 10-15 |
| Overhead Triceps Extension | 2 × 10-15 |

## Pull Day A (Heavy)

| Exercise | Sets × Reps |
|----------|-------------|
| Bent Over Barbell Row | 4 × 4-6 |
| Weighted Pull-ups | 3 × 8-12 |
| Face Pull | 3 × 10-15 |
| Barbell Curl | 3 × 8-12 |
| Hammer Curl | 2 × 10-15 |

## Legs Day A (Heavy)

| Exercise | Sets × Reps |
|----------|-------------|
| Back Squat | 4 × 4-6 |
| Romanian Deadlift | 3 × 8-12 |
| Leg Press | 3 × 10-15 |
| Leg Curl | 3 × 10-15 |
| Standing Calf Raise | 4 × 8-12 |

## Push/Pull/Legs B Days

B days mirror the A-day movement patterns at 8-12 or 10-15 reps, using variations:
- **Push B:** Incline barbell, seated OHP, dumbbell fly, cable lateral raise, skull crusher
- **Pull B:** Chest-supported row, lat pulldown, cable row, preacher curl, face pull
- **Legs B:** Front squat or hack squat, single-leg RDL, leg extension, leg curl, seated calf raise

## Progression

- **Double-progression:** reach top of rep range for all sets, add 2.5 kg (upper) / 5 kg (lower)
- Start next session at bottom of rep range with new weight
- If unable to complete minimum reps: reduce load 5-10%, rebuild

## 3-Day Variant

Run Push/Pull/Legs once per week (Mon/Wed/Fri) for lower-frequency hypertrophy training.

> Each muscle group trained 2x/week. For autoregulated volume, see `rp_hypertrophy`. For power-hypertrophy blend, see `phul`.
