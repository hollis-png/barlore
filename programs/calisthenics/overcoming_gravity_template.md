# Overcoming Gravity Skill Progression Template

*Overcoming Gravity* (2nd edition, 2016) by Steven Low is the most systematic publicly available text on calisthenics periodization and gymnastics-derived skill training. It differs from milestone-only programs like the BWF Recommended Routine by embedding skill progressions within a **periodized framework** that explicitly manages push/pull volume balance, connective tissue adaptation timelines, and skill density.

The system's central insight is that **advanced calisthenics skills fail not because of insufficient strength but because of imbalanced programming**: excessive pulling without horizontal push counterbalance causes elbow tendinopathy; excessive skill volume without structured deloads causes connective tissue overuse; and missing hollowbody mechanics limit every planche and front lever progression regardless of raw strength.

This template represents the program structure Low presents for intermediate athletes targeting the muscle-up, handstand push-up, and front lever/planche foundation skills.

## Who This Is For

- Athletes who have completed BWF Recommended Routine or equivalent
- Minimum baselines: 10 strict pull-ups, 5 parallel bar dips, 15-second dead hang, hollow body hold 30 s
- Skill targets: ring muscle-up, wall HSPU, tuck front lever, tuck planche
- Training age 1–2+ years

## 3-Day Weekly Schedule

| Day | Vertical Pull Pair | Horizontal Pull Pair | Push Skill | Core |
|-----|-------------------|---------------------|-----------|------|
| Day 1 | Vertical pull + HSPU progression | Inverted row + horizontal push | Ring dips | Hollow body |
| Day 2 | Weighted pull-up | Inverted row | Parallel dips + pushup variations | Pallof press |
| Day 3 | Vertical pull + HSPU progression | Inverted row | Ring dips | Hollow body |

Rest at least one day between sessions. Friday/Saturday are the most common rest days for a Mon/Wed/Fri structure.

## Session Structure

OG uses a **superset-style pairing** system where antagonist movements are paired with 60–90s rest between exercises:

1. **Warm-up** (5 min): scapular pull-ups + wrist prep + hollow body holds
2. **Pair A** — Vertical Pull + Vertical Push: 3–5 rounds
3. **Pair B** — Horizontal Pull + Horizontal Push: 3–5 rounds
4. **Skill practice** — 10–15 min on current skill target (muscle-up / HSPU / planche / front lever)
5. **Core finisher**: hollow body + anti-rotation

## Skill Day Structure (Pair Format)

Each skill pair performs A, rest 60–90s, B, rest 60–90s, then repeat:

| Pair | Exercise A | Exercise B |
|------|-----------|-----------|
| Pair A | Vertical Pull tier | Ring Dips or HSPU |
| Pair B | Inverted Row tier | Push-up progression tier |

## Push/Pull Volume Balance (Non-Negotiable)

The most common OG programming mistake is overloading pulling work. Approximate targets:

| Push type | Volume | Pull type | Volume |
|-----------|--------|-----------|--------|
| Vertical push (dips + HSPU) | 15–25 reps/session | Vertical pull | 15–25 reps/session |
| Horizontal push | 15–25 reps/session | Horizontal pull | 15–25 reps/session |

If vertical pulling significantly outpaces pushing, reduce pull volume or add push volume before the next session.

## Connective Tissue Management

OG is explicit that the connective tissue timeline for planche and front lever is **6–18 months** of consistent work — far exceeding the 4–8 weeks required for muscle strength gains at equivalent positions. Management protocols:

- Progress skill difficulty only when current tier is stable for ≥ 3 consecutive sessions
- Deload every 8–12 weeks: 40% volume reduction, one tier easier
- Stop every set 2 reps before technical failure — failed attempts in skill positions reinforce incorrect motor patterns
- If elbow, wrist, or shoulder discomfort develops: reduce skill difficulty by two tiers immediately

## Progression Ladder Quick Reference

| Skill | Entry | Intermediate | Goal |
|-------|-------|-------------|------|
| Front Lever | Tuck (10 s) | Advanced Tuck → One-leg | Straddle (8 s) |
| Planche | Tuck Push-up | Pseudo Planche Push-up | Straddle Hold (5 s) |
| HSPU | Pike Push-up | Wall HSPU (partial) | Wall HSPU (full ROM) |
| Muscle-up | Bar Negatives | Band-assisted | Strict Ring Muscle-up |

## Key Rules

- **Balance is not optional.** Push and pull volume must remain in approximate balance within each session. Imbalance accumulates across weeks and manifests as elbow or shoulder pain.
- **Skill practice belongs at the beginning of the session.** Low is explicit: skill work requires a fresh CNS. Attempting skill progressions after strength sets produces lower-quality practice and reinforces compensated patterns.
- **Never skip scapular activation.** The scapular pull-up warm-up is a health maintenance protocol, not warm-up filler.
