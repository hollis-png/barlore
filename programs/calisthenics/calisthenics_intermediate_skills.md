# Calisthenics Intermediate Skill Development

After establishing the base pulling, pushing, and core capacity from beginner programs (BWF Recommended Routine), intermediate calisthenics shifts toward **skill acquisition**. The target movements at this stage — ring muscle-up, handstand push-up, pistol squat, and L-sit — require both the strength to produce the movement and the technical coordination to execute it correctly. Training must address both dimensions.

## Who This Is For

- Trainees who have completed BWF Recommended Routine or equivalent
- Minimum baselines: 10 strict pull-ups, 15 push-ups with full range, 30-second dead hang, 5 parallel bar dips
- Goals: ring muscle-up, handstand push-up, L-sit to tuck planche progressions

## 4-Day Schedule

| Day | Focus |
|-----|-------|
| Monday | Pull strength + Ring push |
| Tuesday | Horizontal push/pull + Core |
| Wednesday | Skill practice only (low volume, fresh CNS) |
| Thursday | Pull strength + Ring push |
| Friday | Horizontal push/pull + Core |
| Sat–Sun | Rest or Zone 2 cardio |

## Skill Work (Wednesday — Dedicated Skill Day)

Wednesday is for **technique practice**, not strength accumulation. Low fatigue, fresh nervous system:

| Skill | Target | Progression ladder |
|-------|--------|--------------------|
| Muscle-up | 3–5 reps | Ring support hold → bar muscle-up negatives → band-assisted muscle-up → strict muscle-up |
| Handstand push-up | 5 reps | Pike push-up → elevated pike → wall HSPU → freestanding HSPU |
| L-sit | 10–15 s | Tuck L-sit → single-leg L-sit → full L-sit on parallettes |
| Pistol squat | 5 per side | Box pistol → assisted pistol → full pistol |

Spend 10–15 minutes on each skill, then stop. Skill practice with fatigue reinforces poor patterns.

| Exercise | Sets × Reps |
|----------|-------------|

## Progression Rules

1. Move to next skill variation only after 3 consecutive sessions completing 3 × 5 with controlled form
2. Never train a skill to failure — stop 2–3 reps before form breaks
3. Wrist, elbow, and shoulder soreness is common; see `connective_tissue` for management
4. Gelatin + Vitamin C protocol (pre-training) is particularly valuable for ring work and wrist-loading skills

> Entry point: `bwf_recommended_routine`. For advanced skill targets: `calisthenics_advanced_skills`. Injury context: `connective_tissue`, `load_management`.
