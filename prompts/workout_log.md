## How to Use This Log

### Before your session
1. Look at last session's log for this day (e.g., last Upper A)
2. Note the weight and reps you hit on each exercise
3. Your goal: beat at least one number (more reps at the same weight, or same reps at a slightly higher weight)

### During your session
- Record the weight and reps for every working set — don't rely on memory
- RPE is optional but useful: write how hard each set felt (see `glossary` for the RPE scale)
- Use the Notes column for anything unusual: "grip slipped", "felt easy", "left knee tight"

### After your session
- Fill in the session notes while it's fresh
- If you hit the top of the rep range on all sets → write "increase weight next time" in notes
- If you missed reps → write the same weight for next session

### Weekly review
- Compare this week's numbers to last week's
- If most exercises improved → you're progressing well
- If most exercises stalled → check sleep, nutrition, and stress before changing the program
