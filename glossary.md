# Glossary

Canonical term reference. Every entry must use the canonical name in headings and the `name` field; all other forms go in `aliases`. This prevents the same concept being referred to inconsistently across entries.

## Movement Patterns

| Canonical | Aliases | Notes |
|-----------|---------|-------|
| squat | back squat, front squat | Knee-dominant, vertical torso to moderate lean |
| hinge | hip hinge, deadlift pattern | Hip-dominant, minimal knee flexion |
| horizontal press | bench, push | Pressing away from the torso |
| vertical press | overhead press, OHP | Pressing overhead |
| horizontal pull | row | Pulling toward the torso |
| vertical pull | pull-up, pulldown | Pulling from overhead |

## Intensity & Effort

| Canonical | Aliases | Definition |
|-----------|---------|------------|
| 1RM | one-rep max | Maximum load for a single repetition |
| e1RM | estimated 1RM | 1RM estimated from submaximal sets |
| RPE | rate of perceived exertion | Subjective effort scale, 1–10 |
| RIR | reps in reserve | Reps left before failure |

## Credibility Tiers

Used in the `sources[].credibility` field, from strongest to weakest evidence:

| Tier | Meaning |
|------|---------|
| `meta_analysis` | Systematic review or meta-analysis |
| `rct` | Randomized controlled trial |
| `expert_consensus` | Position stance from domain experts |
| `practitioner` | Experienced coach heuristic |
| `anecdotal` | Tradition or gym lore |
