# Box Squat

The box squat is a squat performed to a box or bench set at a fixed height, giving a consistent depth reference and a brief pause at the bottom. It is used to teach depth, build confidence, and develop the bottom-position drive.

## Execution

1. Set the box so the squat hits the target depth at the top of it
2. Set up as for a back squat, bar on the upper back
3. Sit back onto the box under control, shins close to vertical
4. Pause briefly without fully relaxing
5. Drive up explosively from the box

## Common Faults

- **Crashing onto the box** — loss of control, defeats the purpose
- **Fully relaxing on the box** — releases tension and stresses the spine
- **Rocking forward to stand** — should drive straight up from a stable base

## Variations

| Variation | Key difference | Best for |
|-----------|----------------|----------|
| Low box | Below parallel | Advanced bottom-strength work |
| Parallel box | Hip crease at knee | Depth calibration |
